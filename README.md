# OKSBDC Chatbot

A chat widget for the Oklahoma SBDC website, with a staff dashboard for managing responses and reviewing conversations. Built with React/Vite, Express, Gemini, and a local OKSBDC knowledge store.

- [Dashboard user guide](docs/DASHBOARD_USER_GUIDE.md) — staff workflows for reviewing conversations and maintaining answers.
- [Developer guide](docs/DEVELOPER_GUIDE.md) — local setup, repository structure, development, and testing.
- [Production handbook](docs/PRODUCTION_HANDBOOK.md) — deployment, configuration, storage, and operations.
- [Documentation index](docs/README.md) — releases, incidents, and detailed references.
